Array Operations
-----

$push add newelement  the array
$pull delete element from array
$each to add multiple elements
$pop deletes element

db.movie.update({name:'3 idiots'},{$push:{actor:'aaa'}})

$each
-----
db.movie.update({name:'3 idiots'},{$push:{actor:{$each:["yyy","zzz","xxx"]}}})

db.movie.update({name:'3 idiots'},{$push:{actor:{$each:["pune","mumbai","nagpur"] ,$position:2}}})

deleting elements from array
-----------------------

delete last value
db.movie.update({name:'3 idiots'},{$pop:{actor:1}})

delete first value
db.movie.update({name:'3 idiots'},{$pop:{actor:-1}})


delete any value
db.movie.update({name:'3 idiots'},{$pull:{actor:'aaa'}})

delete multiple values
db.movie.update({name:'3 idiots'},{$pull:{actor:{$in:['pune','mumbai','nagpur']}}})

find sum ratings
--------------------
display 5 topmost rated movies and arrange them namewise
db.movie.aggregate({$sort:{rating:-1}},{$limit:5},{$project:{name:1,rating:1,price:1,_id:0}}) 
 

find sum price of all movies 
db.movie.aggregate({$group:{_id:null,total:{$sum:'$price'}}})
over()

find sum price of all movies ,avg,min,max
db.movie.aggregate({$group:{_id:null,total:{$sum:'$price'},
                                     average:{$avg:'$price'},
                                     min:{$min:'$price'}}})


avg price rating wise
----------------------
db.movie.aggregate([{$group:{_id:'$rating',avg_price:{$avg:'$price'}}}]) 

avg price rating wise sort on rating desc
------------------------------------------
db.movie.aggregate([{$group:{_id:'$rating',avg_price:{$avg:'$price'}}},{$sort:{_id:-1}}]) 

topmost rated movies and arrange them based on name
----------------------------------------------
db.movie.aggregate([{$sort:{rating:-1}},{$limit:5},{$sort:{name:1}},{$project:{name:1,rating:1,_id:0}}])

sum price of all movies and avg rating of all movies
--------------------------------------------------
db.movie.aggregate([{$group:{_id:null,
                     sump:{$sum:'$price'}}}])
db.movie.aggregate([{$group:{_id:null,
                     sump:{$sum:'$price'},avgp:{$avg:'$price'}}}])
