Set Operators:-
1.union:- use to combine the result-set of two or more select statements.
select * from t1 union select * from t2;
+------+----------+
| id   | city     |
+------+----------+
|    1 | Pune     |
|    2 | Mumbai   |
|    3 | Hydrabad |
|    4 | Chennai  |
|    1 | Surat    |
+------+----------+

2.union all:-operator takes duplicate values in the result set.
select * from t1 union all select * from t2;
+------+----------+
| id   | city     |
+------+----------+
|    1 | Pune     |
|    2 | Mumbai   |
|    3 | Hydrabad |
|    4 | Chennai  |
|    1 | Surat    |
|    2 | Mumbai   |
|    3 | Hydrabad |
|    4 | Chennai  |
+------+----------+

3.intersect:-operator returns rows that are common in both the result set.
select * from t1 intersect select * from t2;
+------+----------+
| id   | city     |
+------+----------+
|    2 | Mumbai   |
|    3 | Hydrabad |
|    4 | Chennai  |
+------+----------+

4.except:-operator is used to deduct the result of one query from the result of another.
It only returns the entries unique to the first query and which do not appear in the second query.

select * from t1 except select * from t2;

| id   | city |
+------+------+
|    1 | Pune |
+------+------+
